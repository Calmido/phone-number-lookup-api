# API terms

The current terms are in [api-terms.md](api-terms.md), version 1.0. Every earlier version will be kept
alongside it, as `api-terms-<version>.md`, when a new one replaces it.

The key signup shows the version the server knows and records it with the key. A change to the terms
applies as art. 14 says: key holders hear of it by e-mail before it applies.
